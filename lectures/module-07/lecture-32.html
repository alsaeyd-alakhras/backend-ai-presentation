    'mode' => 'payment',
    'line_items' => [[
        'price_data' => [
            'currency' => 'usd',
            'product_data' => ['name' => 'Order #' . $order->id],
            'unit_amount' => (int) ($order->total * 100),
        ],
        'quantity' => 1,
    ]],
    'success_url' => route('checkout.success', $order),
    'cancel_url' => route('checkout.cancel', $order),
]);
IMPORTANT
Stripe يتعامل غالباً بالسنت لذلك نضرب في 100.
نربط كل session بطلب معروف مسبقاً داخل النظام.
النجاح الظاهر في الواجهة ليس وحده المصدر النهائي للحقيقة.

Best Practice06 / 09
أفضل ممارسات في تكامل الدفع
DO THIS
اعتمد على webhook لتأكيد الدفع النهائي.
احفظ provider ids داخل قاعدة البيانات.
اختبر success وcancel وwebhook محلياً باستخدام test keys.
AVOID
اعتبار العودة إلى `success_url` دليلاً نهائياً على الدفع.
عدم التحقق من webhook signature.
دمج كل منطق الدفع داخل controller واحد طويل.
