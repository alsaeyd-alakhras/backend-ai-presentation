المشكلة: نفس الشرط يتكرر في كل Query

تكرار

أخطاء

Local Scope03 / 09
تعريف Local Scopes داخل الموديل
Product.php
PHP
public function scopeActive($query) { return $query->where('is_active', true); } public function scopeFeatured($query) { return $query->where('is_featured', true); } public function scopeInStock($query) { return $query->where('stock', '>', 0); }
Naming Rules
اسم الدالة يبدأ بـ `scope` داخل الموديل.
الاستخدام الخارجي يكون بدون `scope` مثل `active()`.
اختصر كل scope لفكرة واضحة واحدة.

Scope Params04 / 09
Scopes مع Parameters والبحث
Dynamic Scope
PHP
public function scopeByCategory($query, int $categoryId) { return $query->where('category_id', $categoryId); } public function scopeSearch($query, ?string $term) { return $query->when($term, fn ($q) => $q->where('name', 'like', "%{$term}%") ); }
Controller Usage
PHP
$products = Product::active() ->inStock() ->byCategory($request->category) ->search($request->search) ->latest() ->paginate(12);

Global Scope05 / 09
متى نستخدم Global Scope؟
Create Scope Class
BASH + PHP
php artisan make:scope ActiveProductScope class ActiveProductScope implements Scope { public function apply(Builder $builder, Model $model): void { $builder->where('is_active', true); } }
Apply in Model
PHP
protected static function booted(): void { static::addGlobalScope(new ActiveProductScope); }
استخدمه فقط إذا الشرط مطلوب في 90%+ من الحالات.

Bypass06 / 09
تجاوز الـ Global Scope في Admin
Normal Behavior
PHP
Product::all(); Product::where('price', '>', 100)->get(); // includes is_active = true automatically
Bypass
PHP
Product::withoutGlobalScope(ActiveProductScope::class)->get(); Product::withoutGlobalScopes()->get();
الزوار: مع Scope تلقائي.
الإدارة: يمكن رؤية كل السجلات.

Best Practice07 / 09
قواعد عملية لاختيار Scope المناسب
Use Local
عند الحاجة المرنة والمتغيرة.
عند الرغبة بتركيب Scopes متعددة.
Use Global
عند شرط أساسي دائم مثل active products.
عند حماية الواجهات العامة تلقائياً.
Avoid
تحويل كل where إلى scope بلا داعي.
Global scope مع قواعد متغيرة لكل شاشة.
