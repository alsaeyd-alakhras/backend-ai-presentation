Concept02 / 09
فهم علاقة One-to-Many بسرعة
Category (Parent)
الفئة الواحدة تحتوي عدة منتجات.
المفتاح الأساسي: `categories.id`.
Product (Child)
كل منتج ينتمي لفئة واحدة.
المفتاح الأجنبي: `products.category_id`.
قاعدة ذهبية: `hasMany` على الأب، و`belongsTo` على الابن.

N+1 Problem05 / 09
المشكلة الشهيرة: N+1 Queries
Bad Pattern
PHP
$products = Product::all(); foreach ($products as $product) { echo $product->category->name; } // 20 products => 21 queries
Why Dangerous
يزيد زمن الاستجابة بشكل كبير.
يضغط قاعدة البيانات في الشاشات الكثيفة.
يزداد الضرر مع كل نمو في البيانات.

Eager Loading06 / 09
الحل: with() و withCount()
with()
PHP
$products = Product::with('category')->get(); foreach ($products as $product) { echo $product->category->name; } // always 2 queries
withCount()
PHP
$categories = Category::withCount('products')->get(); // $category->products_count Product::with('category:id,name,slug')->get();

Nested Loading07 / 09
تحميل متقدم مع شروط Nested Eager Loading
Example
PHP
$categories = Category::with([ 'products' => function ($query) { $query->active()->inStock()->latest(); } ])->get();
Rule of Thumb
إذا استخدمت علاقة داخل loop استخدم `with()` مباشرة.
حمّل الأعمدة التي تحتاجها فقط.
راقب عدد الـ queries عبر Debugbar.
