sync family06 / 09
الأهم في النماذج: sync()
Sync API
PHP
$product->tags()->sync([1, 2, 3]); $product->tags()->syncWithoutDetaching([4, 5]); $product->tags()->toggle([1, 2, 3]);
When to use
`sync` عند حفظ form نهائي لقائمة الوسوم.
`syncWithoutDetaching` لإضافة وسوم بدون حذف القديمة.
`toggle` لتبديل سريع في واجهات تفاعلية.
