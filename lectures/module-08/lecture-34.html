استخدام ProductResource بدل JSON الخام

class ProductResource extends JsonResource
{
    public function toArray($request): array
    {
        return [
            'id' => $this->id,
            'name' => $this->name,
            'slug' => $this->slug,
            'price' => $this->price,
            'category' => new CategoryResource($this->whenLoaded('category')),
        ];
    }
}
WHY RESOURCE
توحد شكل البيانات الخارجة من كل endpoint.
تسمح بإخفاء حقول داخلية غير ضرورية أو حساسة.
تجعل إضافة nested data أسهل عبر `whenLoaded()`.

Best Practice06 / 09
قواعد جيدة عند بناء API للمبتدئ
DO THIS
ابدأ بـ endpoints قراءة واضحة مثل products وcategories.
أعد status code مناسبة مثل 200 و404 و422.
استخدم eager loading قبل `whenLoaded()` حتى لا تقع في N+1.
AVOID
إرجاع models خامة بكل حقولها دون resource.
خلط web routes وapi routes في نفس الملف.
إهمال النسخ `v1` من البداية.
