لماذا نستخدم Seeders و Factories؟

Seeders

بيانات ثابتة ومضمونة مثل Admin user، فئات رئيسية، إعدادات أولية.

Factories

بيانات وهمية بكميات كبيرة لكن شكلها مقنع وقابل للتطوير.

النتيجة

بعد `migrate:fresh --seed` يصبح المشروع جاهزاً فوراً بدون إدخال يدوي ممل.

هذه المحاضرة ليست رفاهية؛ هي ما يجعل بيئة التطوير لديك قابلة للإعادة بسرعة في كل مرة.

Run Seeds08 / 10
التشغيل النهائي: migrate:fresh --seed
MAIN COMMANDS
BASH
php artisan migrate:fresh --seed php artisan db:seed php artisan db:seed --class=ProductSeeder
WHEN TO USE EACH
`migrate:fresh --seed`عندما تريد بيئة نظيفة بالكامل مع كل الجداول والبيانات.
`db:seed`عندما تكون الجداول موجودة وتريد فقط إعادة تعبئة البيانات.
`--class=...`لتشغيل Seeder واحد محدد أثناء الاختبار أو التطوير.
