Migrations06 / 12
ما هي Migrations ولماذا نستخدمها؟
CONCEPT
Migration = ملف PHP يعرّف شكل الجدول والأعمدة والفهارس والعلاقات.
كل تعديل في قاعدة البيانات يُحفظ داخل Git مثل أي كود آخر.
كل الفريق يستطيع إعادة بناء نفس الـ DB بنفس الأوامر.
WHY NOT MANUAL SQL
التعديلات اليدوية تضيع ولا تكون موثقة.
يصعب معرفة من أضاف عموداً ومتى ولماذا.
مع Migrations يصبح rollback والـ fresh rebuild منظماً وآمناً.
في Laravel 12 يوجد Migration جاهز لجدول `users`، لذلك لا نعيد إنشاءه من الصفر؛ نعدّله أو نضيف Migration جديدة عند الحاجة.

Artisan Commands07 / 12
أوامر Artisan الأساسية لإدارة الـ Database
COMMANDS
BASH
php artisan migrate php artisan migrate:rollback php artisan migrate:status php artisan migrate:fresh --seed
WHEN TO USE
`migrate`يشغّل فقط الـ migrations الجديدة غير المنفذة.
`rollback`يتراجع عن آخر batch إذا احتجت تصحيحاً سريعاً.
`status`يعرض لك ما تم تنفيذه وما يزال pending.
`fresh --seed`يمسح كل الجداول ثم يعيد بنائها مع البيانات الوهمية.

الطريقة الحديثة لكتابة Foreign Keys
MODERN STYLE
PHP
$table->foreignId('category_id') ->constrained() ->cascadeOnDelete();
OLDER EQUIVALENT
PHP
$table->unsignedBigInteger('category_id'); $table->foreign('category_id') ->references('id') ->on('categories') ->onDelete('cascade');
استخدم `foreignId()->constrained()` كلما كان اسم العمود متوافقاً مع الجدول المرجعي؛ الكود يصبح أوضح وأسهل قراءة.
