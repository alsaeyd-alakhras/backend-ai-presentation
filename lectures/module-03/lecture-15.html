Query Pattern03 / 09
استخدام `when()` يجعل query الصفحة نظيفة جداً
SHOP QUERY
PHP
$products = Product::query() ->where('is_active', true) ->when($request->category, fn($q, $slug) => $q->whereHas('category', fn($q) => $q->where('slug', $slug)) ) ->when($request->search, fn($q, $s) => $q->where('name', 'like', "%{$s}%") ) ->when($request->sort === 'price_asc', fn($q) => $q->orderBy('price')) ->when($request->sort === 'price_desc', fn($q) => $q->orderByDesc('price')) ->when(!$request->sort, fn($q) => $q->latest()) ->paginate(12) ->withQueryString();
WHY IT WORKS
كل filter مستقل وواضح.
إضافة sort جديد لاحقاً سهلة بدون كسر البنية.
مقروء أكثر من تداخل `if/else` الطويل.

Routes06 / 09
الـ routes العامة يجب أن تبقى بسيطة وواضحة
PUBLIC ROUTES
PHP
Route::get('/', [HomeController::class, 'index'])->name('home'); Route::get('/shop', [ShopController::class, 'index'])->name('shop.index'); Route::get('/shop/{product:slug}', [ShopController::class, 'show'])->name('shop.show');
WHY SLUG
الرابط يصبح أوضح للمستخدم ومحركات البحث.
Route Model Binding يعمل مباشرة عبر `{product:slug}`.
يناسب صفحات المتجر أكثر من الاعتماد على ID رقمي فقط.

Experience Notes07 / 09
ما الذي يجعل تجربة المتجر أفضل فعلاً؟
DO THIS
أظهر الفلاتر الحالية للمستخدم بوضوح.
استخدم `withQueryString()` كي لا تضيع خياراته.
اعرض منتجات مشابهة في صفحة التفاصيل لزيادة التصفح.
أخفِ المنتجات غير النشطة عن الزوار دائماً.
AVOID
إظهار منتجات غير متاحة أو غير نشطة بالخطأ.
روابط منتجات تعتمد على أرقام غير مفهومة فقط.
نسيان Empty State عند عدم وجود نتائج بحث.
