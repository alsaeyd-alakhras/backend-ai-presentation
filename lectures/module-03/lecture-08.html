Concept03 / 09
شو هو Authentication وليش الآن بالذات؟
THE CONCEPT
Authentication = التحقق من هوية المستخدم: مين هو، وهل هو فعلاً صاحب الحساب.
لوحة تحكم SouqPro قادمة بالمحاضرات الجاية — ولازم تكون محمية قبل ما نبنيها، مش بعدها.
بدون Auth، أي زائر يقدر يفتح أي Route حتى لو كان مخصص للإدارة.
خيارات Laravel لعمل Auth
Breeze — الأبسط والأسرع، يجيب Views جاهزة (Login/Register). خيارنا كبداية.
Fortify — منطق Backend فقط بدون Views، مناسب لواجهات مخصصة بالكامل.
Jetstream — Fortify + مزايا إضافية (فرق، 2FA) أثقل من حاجتنا الآن.
من الصفر — تحكم كامل، لكن وقت وجهد كبيرين على شي محلول أصلاً بأمان.
القرار: نبدأ بـ Breeze لأنها بتجيب Frontend/Views جاهزة فوراً — أسلس تجربة أولى لفهم Auth عملياً، وأساس نقدر نبني عليه لاحقاً.

Middleware05 / 09
حماية Route بـ middleware('auth')
PHP
PHP
Route::middleware('auth')->group(function () { Route::get('/dashboard', function () { return view('dashboard'); })->name('dashboard'); });
WHY IT MATTERS
`middleware('auth')` يمنع أي زائر غير مسجل من الوصول لهذا الـ Route.
`->name('dashboard')` يعطي الـ Route اسماً — نستخدم `route('dashboard')` بدل كتابة الرابط يدوياً بكل مكان.
لو الرابط تغيّر لاحقاً، نعدله بمكان واحد فقط والاسم يبقى ثابت.
هذا أول Route فعلي نحميه — قبل ما نبني لوحة تحكم Admin حقيقية بالمحاضرات الجاية.

Guards06 / 09
مفهوم Guard — "الحارس" اللي يتحقق من هويتك
1
طلب دخول
المستخدم يرسل بيانات تسجيل الدخول عبر Form.
2
Guard يتحقق
الـ Guard (افتراضياً `web`) يفتش عن المستخدم بجدول `users` تحديداً.
3
Session مرتبطة
لو صح، الـ Guard يحفظ الهوية داخل Session ليعرفك بكل طلب لاحق.
CONFIG
config/auth.php
'guards' => [ 'web' => [ 'driver' => 'session', 'provider' => 'users', ], ],
WHY IT MATTERS FOR SOUQPRO
لاحقاً رح نميّز بين مستخدمين عاديين (customer) وأدمن — الـ Guard هو الأساس اللي بيخلي هذا التمييز ممكن.
هذه مجرد تمهيد للفكرة والمصطلح — التطبيق الكامل جاي بمحاضرة "Middleware وRoles للأدمن".

Groups & CSRF07 / 09
تنظيم Route Groups والحماية من CSRF
ROUTE GROUPS (BREEZE STYLE)
routes/auth.php
Route::middleware('guest')->group(function () { Route::get('register', [RegisteredUserController::class, 'create']); Route::post('register', [RegisteredUserController::class, 'store']); });
هيك Breeze نفسه بينظّم Routes — الهدف الآن نفهم شكل الكود الجاهز، مش نبني Group من الصفر.
CSRF PROTECTION
BLADE
<form method="POST" action="{{ route('login') }}"> @csrf ... </form>
`@csrf` يولّد Token يتحقق منه Laravel تلقائياً مع كل Form.
يمنع هجوم يخلي موقعاً آخر يرسل طلب باسمك من غير علمك.
