Storage Disks02 / 08
أولاً: افهم الفرق بين local و public
FOLDER MAP
TEXT
storage/ app/ private/ ← local disk public/ ← public disk public/ storage/ ← symlink إلى storage/app/public
RULE OF THUMB
استخدم `local` للملفات الداخلية غير المعروضة للويب.
استخدم `public` للصور التي يجب عرضها في المتصفح.
نفّذ `storage:link` مرة واحدة لربط المسار العام.

Store Image03 / 08
رفع الصورة عند الإضافة
STORE ACTION
PHP
$data = $request->validated(); if ($request->hasFile('image')) { $data['image'] = $request->file('image') ->store('products', 'public'); } Product::create($data);
IMPORTANT DETAILS
Laravel يولد اسماً عشوائياً آمناً للملف.
القيمة المخزنة في DB تكون مثل `products/random.jpg`.
لا تخزن الرابط الكامل داخل قاعدة البيانات.

Replace Image05 / 08
في التعديل: استبدال الصورة مع حذف القديمة
UPDATE IMAGE
PHP
if ($request->hasFile('image')) { if ($product->image) { Storage::disk('public')->delete($product->image); } $data['image'] = $request->file('image') ->store('products', 'public'); } $product->update($data);
WHY DELETE OLD FILE
حتى لا تتراكم ملفات غير مستخدمة داخل التخزين.
يحافظ على المساحة خاصة عند مشاريع الصور الكبيرة.
يبقي البيانات والملفات متناسقة دائماً.
